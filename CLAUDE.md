# Правила проекта «Ритм»

- Язык интерфейса и коммитов — русский. Дизайн: светло-серый фон, белые карточки с крупным скруглением, чёрные кнопки, один акцент (оранжевый), моноширинные подписи капсом.
- Без сборки и зависимостей: чистые ES-модули. Новый JS-файл обязательно добавить в список FILES в `sw.js`.
- **Каждое изменение по просьбе пользователя — новая версия**:
  1. описать изменения в `CHANGELOG.md` в разделе «## [Не выпущено]»;
  2. `scripts/release.sh X.Y.Z "кратко"` (Z — исправления, Y — новые возможности, X — большие перемены);
  3. `git push origin main --follow-tags`.
- Данные пользователя хранятся в localStorage под ключом `ritm:data`. Схему менять только добавлением полей: старые версии в `/v/…` читают те же данные. При несовместимом изменении — поднять `SCHEMA` в `js/store.js` и дописать `migrate()`.
- Перед выпуском проверить в браузере мобильную (390px) и десктопную (1440px) ширину.
