# Ритм

Личный трекер для жизни: привычки, цели на год / месяц / неделю / день, тренировки в зале с таймером отдыха, вес и состав тела с весов Xiaomi S400.

Работает в браузере на телефоне и компьютере, без сервера: данные хранятся на устройстве (localStorage). Можно установить на экран «Домой» на iPhone: Safari → «Поделиться» → «На экран „Домой“».

## Где открыть

После включения GitHub Pages (Settings → Pages → Source: **GitHub Actions**):

- последняя версия: `https://danikchervinskiy.github.io/ritm/`
- любая прошлая версия: `https://danikchervinskiy.github.io/ritm/v/v0.1.0/` (список — в приложении: Настройки → Версии приложения)

## Версии и откат

Каждое изменение выходит отдельной версией `vX.Y.Z`:

1. Изменения описываются в `CHANGELOG.md` в разделе «Не выпущено».
2. `scripts/release.sh X.Y.Z "что изменилось"` — обновляет номер версии и CHANGELOG, делает коммит.
3. `git push origin main` — GitHub Actions сам создаёт тег `vX.Y.Z`, Release с описанием и публикует сайт.

Как откатиться:

- **Просто открыть старую версию** — по ссылке `/v/vX.Y.Z/`. Данные общие для всех версий.
- **Вернуть старую версию как основную** — `git revert` нужных коммитов (или `git checkout vX.Y.Z -- .`, затем коммит) и выпустить как новую версию. История при этом не теряется.
- **Данные** — при первом запуске новой версии приложение само сохраняет копию данных прошлой версии (Настройки → Данные → «Вернуть»). Плюс ручной экспорт в JSON.

## Устройство

Без сборки и зависимостей: обычные HTML/CSS/JS-модули.

```
index.html            оболочка
css/styles.css        дизайн (светлая и тёмная тема)
js/app.js             маршруты, меню, обработка событий
js/store.js           данные, сохранение, резервные копии
js/logic.js           серии, прогресс, рекорды
js/rest.js            таймер отдыха
js/views/*.js         экраны
sw.js                 офлайн-кэш
```

Локальный запуск: `python3 -m http.server 8000` и открыть http://localhost:8000.

## Планы

- Приложение для iPhone (Capacitor): виджеты на экран «Домой», таймер на экране блокировки, импорт веса и % жира из Apple Health.
- Синхронизация между телефоном и компьютером.
- Полный состав тела из облака Xiaomi Home.
